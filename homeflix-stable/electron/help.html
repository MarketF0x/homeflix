Guide d'utilisation Homeflix

Bienvenue dans Homeflix. Ce guide local résume l'essentiel pour naviguer et résoudre les petits problèmes courants sans accès Internet.

Barre supérieure & Navigation

  • La barre personnalisée apparaît quand la souris effleure le haut de la fenêtre ou avec la touche Alt.
  • Les actions disponibles : Actualiser, Forcer l'actualisation (ignore le cache), Zoom ±, Réinitialiser zoom, Quitter.
  • La fenêtre est frameless et maximisée pour simuler le plein écran sans utiliser F11.

Lecture Vidéo

  • La progression est sauvegardée automatiquement; reprendre une vidéo recharge votre dernier point.
  • Les sous-titres peuvent être activés/désactivés dans le lecteur s'ils sont disponibles.
  • En cas de blocage visuel, utilisez d'abord Actualiser puis Forcer l'actualisation.

Performances & Fiabilité

  • Le serveur redémarre automatiquement si un problème est détecté (auto-heal).
  • En cas de crash GPU répété, Homeflix bascule sur un mode logiciel pour rester stable.

Raccourcis utiles

  • Ctrl/Cmd + R : Actualiser.
  • Ctrl/Cmd + Shift + R : Forcer l'actualisation.
  • Ctrl/Cmd + + / Ctrl/Cmd + - : Zoom avant / arrière.
  • Ctrl/Cmd + 0 : Réinitialiser le zoom.
  • Alt : Afficher temporairement la barre si cachée.

Dépannage rapide

Image figée ou liste vide ?
Essayez : Actualiser → Forcer l'actualisation → Redémarrer l'application si le problème persiste.
Redémarrages fréquents
Si l'application se relance plusieurs fois en moins de 5 minutes, notez l'heure et redémarrez le système pour réinitialiser l'environnement GPU / réseau.

Confidentialité

Aucune donnée n'est envoyée vers un service externe tant que vous n'ouvrez pas un lien externe (documentation, sources). Tout reste en local.

Limitations

  • Pas d'accès aux outils de développement (DevTools) pour garantir une interface épurée.
  • Le plein écran natif (F11) est désactivé; le mode maximisé frameless offre déjà une immersion quasi totale.

Support

Ce guide est hors-ligne. Pour une aide avancée, ouvrez la documentation complète quand Internet est disponible.
