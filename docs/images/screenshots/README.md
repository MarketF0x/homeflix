# Screenshots Homeflix

Ce dossier contient les captures d'écran de l'application.

## Screenshots à créer

1. **homepage.png** - Page d'accueil (1920x1080)
2. **video-player.png** - Lecteur vidéo (1920x1080)
3. **video-details.png** - Détails vidéo (1920x1080)
4. **collections.png** - Collections (1920x1080)
5. **settings.png** - Paramètres (1920x1080)

## Comment créer les screenshots

1. Lancez Homeflix en production: `.\homeflix.ps1`
2. Naviguez vers chaque page
3. Prenez une capture (Win + Shift + S)
4. Sauvegardez dans ce dossier
5. Optimisez avec: `python optimize_images.py`

Consultez `../ASSETS_GUIDE.md` pour plus de détails.
