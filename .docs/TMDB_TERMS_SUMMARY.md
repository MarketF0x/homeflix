# ⚠️ IMPORTANT - Conditions d'Utilisation API TMDb

## 📋 Résumé des Conditions pour Usage Commercial

D'après les **API Terms of Use de TMDb** (dernière mise à jour: 20 octobre 2023), voici les points essentiels :

### ❌ USAGE COMMERCIAL INTERDIT SANS ACCORD ÉCRIT

**L'usage commercial de l'API TMDb NÉCESSITE un accord commercial séparé avec TMDb.**

#### Définition d'Usage Commercial (Section 2)

TMDb considère comme usage commercial :

1. **Applications payantes** - Facturer des frais aux utilisateurs pour une application utilisant l'API TMDb
2. **Vente d'applications** - Vendre une application qui utilise l'API TMDb
3. **Sites générant des revenus** - Utiliser l'API sur un site web qui génère des revenus (publicité, abonnements, etc.)
4. **Recommandation de contenu** - Sites générant des revenus via des recommandations de films/séries
5. **Machine Learning/AI** - Entraînement de modèles ML/AI avec les données TMDb

### ✅ Usage NON-Commercial AUTORISÉ

Pour les **applications personnelles et gratuites** :
- ✅ Utilisation gratuite de l'API
- ✅ Pas de frais pour l'utilisateur final
- ✅ Pas de génération de revenus (publicité, abonnements, etc.)
- ✅ Usage personnel et communautaire

### 📝 Exigences d'Attribution (Section 3)

**OBLIGATOIRE pour TOUTE utilisation :**

1. **Logo TMDb** - Afficher le logo TMDb dans votre application
2. **Mention légale** - Inclure la phrase suivante :

```
"This product uses the TMDB API but is not endorsed, certified, or otherwise approved by TMDB."
```

En français :
```
"Ce produit utilise l'API TMDb mais n'est ni approuvé, ni certifié, ni validé par TMDb."
```

### 🚫 Restrictions Importantes (Section 1.C)

- ❌ **Cache limité** - Max 6 mois de cache des données
- ❌ **Pas de dérivés** - Interdiction de créer des dérivés des données TMDb
- ❌ **Pas d'hébergement d'images** - Ne pas utiliser TMDb comme CDN
- ❌ **Pas de ML/AI** - Interdiction d'entraîner des modèles IA avec les données
- ❌ **Pas de masquage** - Transparence totale sur l'identité de l'application

### 🔑 Clé API Personnelle

**Chaque utilisateur DOIT obtenir sa propre clé API :**

1. **Gratuite** pour usage non-commercial
2. **Personnelle** - Non partageable
3. **Révocable** - TMDb peut révoquer à tout moment
4. **Procédure** : https://www.themoviedb.org/settings/api
